SMART 单票 Invoice 助手 — 一页纸使用说明（小白版）
================================================
版本：v0.3（新旧模板兼容完整复核版 / 2026-08-20）
本期只生成 PDF，不会发送邮件。

【你需要准备什么】
1. Windows 10 / 11 电脑
2. 已安装 Microsoft Excel 或 WPS 表格（导出 PDF 用，二选一即可）
3. 「SMART发票助手.exe」（双击即可，不用装 Python）
4. 已确认的 SMART 账单 Excel（.xlsx）

【怎么用】
1. 把 exe 放到任意文件夹（建议单独建一个目录，不要放在桌面临时压缩包里直接双击）
2. 双击「SMART发票助手.exe」
   - 第一次打开可能要等几秒（程序自解压），属正常
3. 选择邮箱类型（QQ / 腾讯企业邮），填写账号和授权码，点「进入系统」
   （本期只用于进入，不会发邮件，也不会记住授权码）
4. 点「浏览」，分别选择：
   - 待处理 Excel 文件夹（里面放已确认账单 .xlsx）
   - 结果保存文件夹（生成的 PDF 会写到这里）
5. 选择导出引擎：自动 / Microsoft Excel / WPS 表格
6. 点「开始生成 Invoice」，完成后点「打开结果」

【结果里有什么】
- 每个柜号一个 PDF，文件名就是柜号，例如 TIIU6724883.pdf
- 如果一次处理多个 Excel，会按账单名分子文件夹
- _logs 里有校验报告 report.xlsx，生成失败时先看这份报告

【常见问题】
Q：只有 WPS 没有 Excel？
A：导出引擎选「WPS 表格」或「自动」即可，不会强制打开微软商店。

Q：窗口缩小看不到进度？
A：主界面可滚动；「03 进度」可展开/收起，日志也可滚动。

Q：要不要装 Python？
A：不要。发给同事的是安装包里的 exe。

Q：点了 exe 没反应？
A：等 5–10 秒。如果仍无窗口，看同目录是否出现「启动失败日志.txt」，把该文件发给技术人员。

Q：旧版账单（柜号和体积写在同一格）能用吗？
A：能。新模板、旧模板都支持，程序会自动识别。

本期不做：自动发送邮件。
